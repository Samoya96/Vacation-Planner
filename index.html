Vacation Planner Mobile App

Vacation Planner is an Android application designed to help users organize their trips and activities. The app supports vacation tracking, excursion management, reminders, and easy sharing of trip details.

Key Features

  • Vacation Management: Add, update, and view upcoming trips.
  • Excursion Tracking: Attach activities to each vacation.
  • Search Tools: Filter vacations by name or date.
  • Alerts: Receive reminders for important dates.
  • Local Storage: All data saved using Room database.
